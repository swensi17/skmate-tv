# SkMate IPTV на телевизоре LG (webOS)

Версия для LG готовится. Будет два способа:

1. **Магазин LG (LG Content Store):** найти SkMate IPTV и нажать «Установить». Приложение проходит проверку LG.
2. **Homebrew Channel:** для тех, кто включил режим разработчика на телевизоре LG; установка из списка приложений Homebrew Channel.

Следите за [Releases](../../../releases) этого репозитория.

Для Android TV, Google TV и Fire TV: [swensi17/skmate-iptv](https://github.com/swensi17/skmate-iptv).
